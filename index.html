Moore's Nim lower up to k piles at once

n piles of tokens. A move lowers up to k piles (Moore 1910) — or, in Exact k-Nim, exactly k piles — each by any positive amount. Whoever moves last wins. Moore's rule: write the piles in binary and add each column mod k+1; you are lost exactly when every column is 0. The Sprague–Grundy value is much harder: the base-(k+1) number M(x) is not it (Berge got this wrong), and an exact formula is known only for n = k+1 (Jenkyns–Mayberry 1980) and, for Exact k-Nim, n ≤ 2k. Click a token to lower that pile to just below it, pick up to k piles, then Move.
